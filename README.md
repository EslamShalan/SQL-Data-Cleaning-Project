# SQL Layoffs Data Analysis

## 📌 Project Overview

This project focuses on analyzing global layoffs data using SQL.

The project is divided into two main stages:

1. Data Cleaning
2. Exploratory Data Analysis (EDA)

The goal is to clean the raw dataset, prepare it for analysis, and extract useful insights using SQL.

---

## 🛠️ Tools Used

- MySQL
- SQL
- Git & GitHub

---

## 🧹 1. Data Cleaning

In this stage, the raw layoffs dataset was cleaned and prepared for analysis.

### Main Tasks

- Identifying and removing duplicate records
- Removing unnecessary spaces from text values
- Standardizing company names
- Standardizing industry values
- Standardizing country names
- Handling NULL and blank values
- Standardizing date values
- Converting columns to appropriate data types
- Preparing the cleaned dataset for analysis

### SQL File

`SQL-Data-Cleaning-Project/Data cleaning project.sql`

### Dataset

`SQL-Data-Cleaning-Project/layoffs.csv`

---

## 📊 2. Exploratory Data Analysis (EDA)

After cleaning the dataset, Exploratory Data Analysis was performed to understand the data and identify important trends and patterns.

### Business Questions

The analysis answers questions such as:

- Which companies had the highest number of layoffs?
- Which industries experienced the most layoffs?
- Which countries had the highest number of layoffs?
- What is the period covered by the dataset?
- Which years experienced the highest number of layoffs?
- Which companies raised the most funding?
- What are the highest and lowest layoff figures?
- How did layoffs change over time?
- What is the rolling total of layoffs over time?

### SQL File

`SQL-EDA-Project/SQL-EDA-Project.sql`
